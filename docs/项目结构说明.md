## 两个管道的 stage 流程

```
PIP:  transcribe → understand(初编+verify复查) → draft → edit → re_transcribe → storyboard → hf_build_pip → review → upscale
V23:  transcribe → understand → draft → edit → storyboard → hf_build → review → upscale
```

**区别**：PIP 多了 `re_transcribe`（剪辑后重新转写，字幕音画同步），画面生成用 `hf_build_pip`（全屏 3D）而非 `hf_build`（卡片）。

## 数据流（PIP 关键链路）

```
transcribe  → words + raw_words（逐字时间戳）
understand  → story_map.keep_ranges（字词级删减后的保留区间）
draft       → edl.ranges（= keep_ranges 直接映射）
edit        → final.mp4（按精确区间剪切）+ edl.ranges 回写
re_transcribe → words/raw_words（新视频时间戳，覆盖）
storyboard  → scenes（基于新时间戳语义分镜）
hf_build_pip → 场景 HTML + 字幕 + 渲染
```

## 关键设计

- **剪辑精确到字**：两步 LLM（初编 + verify 复查）
- **字幕音画同步**：re_transcribe 重新转写
- **画面稳定性三大兜底**：Three.js 缺失 / 省略号 style / 删减过度
- **场景数不锁死**：内容决定
- **横竖屏自适应**：`_detect_orientation` + 动态 fw/fh
- **窗口形状随机**：圆形 / 钝角方
