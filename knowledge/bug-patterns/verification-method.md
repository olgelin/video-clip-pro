# 验证方法：判断数字人状态要看 HTML person-zone，不能只看抽帧

## 坑

验证数字人状态（大竖条/角标/消失/换位）时，只抽几帧给 vision 看，会误判。

**实例**：教育话题 7 帧抽下来 vision 全说"左下角小角标"，我差点误判"A 失效了"。实际 HTML 布局是 角标×3 + 竖条×2 + 消失×2，完全正常。

## 根因

1. 抽帧时间点没对齐场景边界（场景时长不均，t=20 可能还在上一个场景）。
2. rail 竖条场景数字人在画布外，vision 看不到竖条，容易漏判。
3. hidden 场景数字人移出画面，vision 也看不到。

## 正确方法

1. 先看 `hf_build_avatar/beat-N.html` 里的 `data-person-zone` 属性——这是**权威布局**：
   - `corner-bl`/`corner-br` = 角标
   - `hidden` = 消失
   - 无 person-zone + `data-width="1250"` = rail 竖条（横屏分栏，数字人在画布外）
2. 抽帧只用于**复核**渲染效果，不用于**判断布局**。

## 铁律

判断布局看 HTML 属性，判断渲染看抽帧。两者结合，别用抽帧反推布局。
