# 设计决策：数字人编排 + 画面景别

> 这些是"想清楚了才定下来"的决策，改之前先看这里，别推翻重来。

## 1. 数字人编排 = LLM 判断 + 确定性大小（2026-09 定版）

**问题**：数字人摆位（大小/左右/出镜）之前代码锁死，导致"永远大竖条、永远分栏"，单调。

**决策**：
- **大小**由景别 shot_scale **确定性**决定（防 LLM 随机性导致全竖条/全角标）。
- **左右/出镜**由 LLM 读语义判断（L/R/H），灵活创意。
- fallback 硬编码兜底。

**效果**：4 档状态（大竖条左/右、小角标左/右、hidden 消失），"人物与内容轮流当主角"。

## 2. 画面景别 shot_scale（满/小交替）

**问题**：之前"高潮场强制 full"导致连续 3 个满版，单调疲劳。

**决策**：严格交替，开场必 full，绝不连续两个 full。

- full = 内容全屏满版（冲击）
- inset = 缩小留白 + 缩放移动动画（聚焦）

## 3. 横屏 = 竖屏一切 + 分区

**决策**：
- 竖屏：上下分（数字人下/内容上），不左右分（空间窄）。
- 横屏：左右分（640 竖条 + 1250 内容 + 30 缝隙），额外多"左右分区"。
- 景别/换位两者共有。

## 4. 竖条 640 而非 960

用户看 640（=1/3）说"还可以，继续吧"。960（各一半）会让内容区只剩 930，画面更不大气。

## 5. 卡片 = 技法菜单，不是模板（用户红线）

用户明确否定"标准模板 + 四件套缺一不可"。改成 6 技法（四角L角标/顶部高光线/毛玻璃/内发光/渐变边框/光斑扫过）选 2-4 自由组合。

## 6. 数字人素材：合成永远用竖屏

竖屏素材对口型正常，横屏素材 Duix 会死锁。场景方向由 --orientation 决定，横屏时竖屏数字人 crop 进横屏窗口。
