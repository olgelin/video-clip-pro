## 🎨 创意加速器

写代码之前问自己：这个画面能不能让观众在第 0.5 秒愣一下？

- **隐喻降维**：别把"数据增长"做成数字变大。做成一个东西在膨胀、在蔓延、在裂开。
- **一个异物**：每画面放一个"不该在这"的东西。一个静止在动里的、一个亮在暗里的。
- **颜色撒谎**：暖色写冷情绪，冷色写热冲突。反差比和谐更抓人。
- **满而有序**：画面要填满（上下左右都有内容），但分层次、有呼吸感——不是挤成一团，也不是四周留大片空白。
- **速度即叙事**：一个元素 0.5 倍速，旁边一个 3 倍速——速度差本身就讲了故事。

这些是创意方向，不是技术规范。该遵守的规则一条不能少，但在规则之内，敢做意外选择。

## 🎬 画面景别（full 全屏 vs inset 小画面，MUST 遵守）

导演简报会给每个场景一个「画面景别」（full 或 inset），你必须遵守：

- **full = 全屏满版（冲击）**：内容铺满整个画布——大标题 + 满版图表/卡片铺开，撑满、有压迫感。观众一眼看全局。
- **inset = 缩小的小画面（聚焦）**：内容缩成一个 40-60% 大小的"小画面"（一个集中的信息块/卡片/窗口）。观众视线被逼着聚焦它。🔴 **留白区不是纯空白**——必须铺满氛围粒子/隐喻物体/装饰网格/数据流，让整个画布从上到下从左到右都有东西，小画面只是视觉重心。

🔴 inset 小画面怎么"活"起来——从下面 3 个形态里自由选 1 个：
1. **居中小窗**：居中，入场 scale 0.6→1 + 从下方/上方滑入，入场后呼吸缩放 1.0↔1.04；四周铺满粒子/装饰
2. **角落缩位**：缩到左上/右下角，其余空间铺满氛围粒子/隐喻物体/数据可视化背景，缓慢漂移
3. **悬浮漂移**：在画布上持续缓慢移动 + 缩放（translate 1-2px/s + scale 呼吸），像漂浮

🔴 inset 铁律：入场用 scale(0.6→1 或 0.8→1) + 位置移动（translate），不是死板 fade；入场后持续缓慢缩放/漂移，别缩一块静止不动。

## 排版预算（🔴 "凌乱"和"空洞"的克星，必须遵守）

- 🔴 **同屏主体 ≤3 个**：数字人算 1 个主体，所以你的内容主体最多 2 个（比如 1 个大数字 + 1 组卡片）。超过 3 个主体 = 画面乱。
- 🔴 **垂直填满**：内容必须在安全区内**从上到下、从左到右铺满**，上下左右都不留大片空白。横屏内容区也一样——上半屏标题、中半屏核心数据/图表、下半屏卡片/趋势线，三层都要有内容。如果内容偏少，用更大字号、更多数据卡片、更宽的间距来填满。🔴 **禁止"居中一小块四周空"**（内容缩在画面中央一小块、四周大片空白 = 空，判不合格）。
- 🔴 **左右平衡**：内容分布必须左右均衡，禁止「左边堆满右边全空」或「右边重左边轻」。如果左侧放了大数字，右侧就要有卡片/图表来平衡；如果重心在中央，两侧对称留白。
- 🔴 **hero 一屏一个**：一个画面里只有一个"hero 级"造型（超大数字 140px+ 或超大标题 120px+），其他都是辅助。两个都抢戏 = 无重点。
- 🔴 **图例必须对应图形**：画面里如果画了图例（legend），图表里必须有对应的图形元素。禁止「图例写了"退潮曲线"但画面里没有任何曲线」这种孤岛图例——图例和图形不对应 = 删掉图例，别让它悬空。
- 🔴 **标签必须带数值**：每个标签/数据项（如"市场标价""零售价""成本"）后面**必须跟着对应的真实数值**，禁止只有标签没有数字的空壳标签——写标签就要填数字，填不了数字就删标签。
- 🔴 **禁止碎片文字乱入**：画面里每个文字都要有明确归属（标题/标签/数据/说明）。禁止孤立的、无上下文的小字碎片。写完检查一遍：每个 span/div 的文字都能对上它的卡片或标题吗？对不上就删。
- 🔴 **画面文字 ≤12 字提炼**：画面文字是口播的提炼（≤12 字），禁止把字幕整句抄上屏。字幕和画面文字重复 = 双份同屏、观感差。
- 🔴 **底部字幕安全区（内容绝对禁入）**：画面底部 **150px（横屏）/ 180px（竖屏）** 是底部字幕的位置。**任何元素**——数据卡片、图表、标签、图例、注脚、底部装饰文字、小数字、副标题——**一律禁止进入这个区域**。⚠️ **不是容器 `bottom:150px` 就行**：文字字体高度会向下溢出，所以**容器 bottom 必须 ≥180px（横屏）/ 200px（竖屏）**，给最底部一行文字留足 30px 字体余量。内容全部集中在字幕区之上，底部留干净。

## 配色与情绪关联

{color_palette}

🔴 **全程蓝色科技风，禁止红/橙/绿**（这是全篇唯一铁律，贯穿所有场景和元素）。根据 mood 在蓝/青/紫/金四个色相内调明暗和主次比重（不换色相）：
- 冷静/理性 → 蓝 + 青为主（亮、清爽）
- 冲突/愤怒/紧张 → 紫 + 蓝为主（暗、压抑，紫主色占比拉高）
- 压迫/沉重 → 深紫 + 暗蓝（最暗、低饱和）
- 希望/升华 → 青 + 金点缀（亮、向上）

每场景 ≥2 种颜色，核心数据高亮色。🔴 情绪靠「明暗+比重」表达，禁止用红色表达愤怒、绿色表达增长、橙色表达冲突。背景色一律深色蓝紫渐变（#060618→#0A0C26→#0C1030 方向），不管话题是危机还是希望，背景不准变——情绪用霓虹亮色点缀表达：青色=数据增长/正向，紫色=警示/关键数字，金色=关键洞察，蓝色=基础信息。

🔴 **金色 ≠ 橙色（LLM 最容易犯的错）**：金色是 `#FFD700`（黄偏金，允许），橙色是 `#FF8C00`/`#FFA500`/琥珀色/`#FFB347`（黄偏红，🔴 禁止）。写颜色时严格用 `#FFD700`，禁止任何偏橙的色值——"暖橙色标签""琥珀色边框"都是橙色，判违规。

🔴 **金色是"点睛"不是"铺色"**：全屏金色最多 1-2 处（比如 1 个核心洞察数字、1 个关键标签）。禁止大面积铺金色——多个金色标签/大数字并列会刺眼、突兀、破坏冷色统一感。

🔴 **警示/高危/负面数据也禁止橙红绿（LLM 最容易"合理化突破"）**：哪怕"月供占工资175%""亏损""暴跌""下跌"这种高危/负面数据，也禁止用橙/红/绿表达。LLM 常觉得"警示数据用红色是合理的"，这是错的——全篇铁律无任何例外。高危/负面用**紫色 #A855F7**（可配深色底），正面/增长用**青色 #00D4FF**，关键洞察用**金色 #FFD700**。记住：橙、红、绿三色在任何语义下都不出现。

## 🃏 卡片技法菜单（信息卡/数据卡）

🔴 卡片要有精致质感，但**禁止套模板**——从下面技法里按语义选 2-4 个自由组合，每张卡片组合不同、不千篇一律：

1. **四角 L 形角标**：四角小 L 形发光括号（2px border 拼）
2. **顶部高光线**：卡片顶部 1px 渐变发光线条
3. **毛玻璃**：`backdrop-filter:blur(20px) saturate(180%)` + 半透明深色背景
4. **内发光**：`box-shadow:0 0 0 1px rgba(主色,0.06) inset` 主色微光
5. **渐变边框**：主色→青色渐变描边
6. **光斑扫过**：亮点沿边框/表面扫过（GSAP 循环）

🔴 卡片统一规范（不变的部分）：
- **统一外观**：同一场景内所有卡片用同一套视觉语言——同样圆角(16px)、同样边框色、同样背景透明度。
- **统一三层**：标签(12-14px 小字/大写/低饱和) → 数值(36-64px 大字/JetBrains Mono) → 说明(14-16px 灰字)。三层齐才是完整卡片。
- **边框带色**：卡片边框 = 主色 `rgba(主色,0.25)`，不是白/灰边框。
- **发光克制**：数值发光 `text-shadow:0 0 16px rgba(主色,0.35)` 最多 1 层。
- **间距对齐**：卡片间 gap 16-24px，flex/grid 对齐，禁止乱堆乱叠。

## 数据可视化

🔴 **铁律：每场景必须包含 ≥3 个数据元素（硬要求，不是建议）。** quote_hero、compare、timeline_event 最容易漏——但它们也需要 KPI 卡片/进度条/趋势数字。纯文字标题场景就是失败。

🔴 **卡片/大数字必须用真实数字，禁止写 0 或占位**：导演简报的 brief 里有「数据：xxx」字段，以及「口播参考」里的真实数字——卡片 C 位大数字必须填这些真实数字（如"1000万""8亿""30min"），禁止写"0万""0%""0分"这种空占位。口播有数字，画面就必须放大那个数字。

数字冲击(scale:2.5→1) | 进度条(width:0%→目标值) | KPI 卡片(2-3 并排) | 对比条(A vs B + 差值) | 趋势线(SVG 折线 3-4 点)

- line_chart: SVG polyline + stroke-dasharray 动画绘制
- pie_chart: SVG circle + stroke-dasharray 扇形，最多 6 片
- kpi_grid: 3-4 个卡片并排，每个含标签+数值+趋势箭头

🔴 **镜头运动 MUST**：导演简报给了 camera_motion。把你所有内容包进 `<div id="main-content">`，然后实现对应镜头运动：
- dolly_in: `tl.from("#main-content", {scale:1.15, duration:1.2, ease:"power2.out"}, 0)`
- dolly_out: `tl.from("#main-content", {scale:0.9, duration:1.0, ease:"power2.out"}, 0)`
- pan_left: `tl.from("#main-content", {x:-60, duration:0.8, ease:"power3.out"}, 0)`
- pan_right: `tl.from("#main-content", {x:60, duration:0.8, ease:"power3.out"}, 0)`
- zoom_in: `tl.from("#main-content", {scale:0.8, duration:0.6, ease:"back.out(1.4)"}, 0)`

- **quote_hero**：中心大字 80-120px + 底部标签 pill 4-6 个 + 叙事隐喻物体+动画
- **data_impact**：中心大数字 140px + 3-4 KPI 卡片 + 趋势条。下半屏必须有内容。核心数字 112-140px 弹入(scale:2.5→1) → 扫光线横穿 → 进度条 pulse 呼吸 → 标题逐字渐入+blur消散。
- **compare**：左右分裂 + 分割线 + 差值标注 + 隐喻物体
- **flow**：垂直/横向节点链 + 粒子连接 + 进度条
- **list_alert**：3-5 项卡片 + 项间连接 + 关键项高亮
- **timeline_event**：主体元素 + 时间标记 + 数据条。🔴 时间轴必须"慢慢画出来"，不是一次性显示：轴线从左到右 stroke-dasharray 逐步延伸（0.8-1.2s，power2.inOut）、节点逐个点亮（stagger 0.3s，每个节点 scale 0→1 + 发光 + 年份浮现）、每个节点标签在点亮后 0.2s 才浮现、当前节点持续 pulse 呼吸（repeat:3 yoyo）

## 🔥 Three.js 动画铁律（确定性版——旋转是时间 t 的纯函数）

🔴 **旋转铁律（同步 object 属性，禁止 needsUpdate 下坠）**：粒子用「整体旋转」——`pts.rotation.y = t * 0.4`（绕 y 轴，同步，HyperFrames seek 下可靠）。**绝对禁止**逐帧改 buffer position + `needsUpdate=true`——needsUpdate 是异步 GPU 上传，HyperFrames seek 截图时没反映到画面 → 粒子静止（实测帧差 0，这是「画面静态」的头号根因，video-factory 早就根治）。

🔴 **代码模板（rd 必须是 t 的纯函数）**：
- `function rd(t){pts.rotation.y=t*0.4;r.render(s,cam)}`（整体绕 y 轴旋转）
- 可选微摆：`pts.rotation.x=Math.sin(t*0.2)*0.06`（绕 x 轴辅助，幅度小）
- 🔴 禁止 `p[i*3+1]-=spd[i]`（累积下坠 desync）、禁止 `needsUpdate=true`（异步静止）、禁止绕 x 轴当主运动（帧差也接近 0）

🔴 **旋转速度**：`rotation.y=t*0.3~0.5`（每秒 0.3-0.5 弧度）。禁止 <0.2（太慢静止）。

🔴 **直接复制技法菜单的完整 rd 函数骨架**（技法菜单已经是 rotation.y 正确写法），不要自己改成下坠 + needsUpdate。

可选呼吸（让粒子有生命，但只是辅助，主动态靠旋转）：
- `material.opacity = 0.5 + Math.sin(t*1.5)*0.3`
- 颜色 lerp 呼吸
- `cam.position.y = 3 + Math.sin(t*0.5)*0.5`

## 背景层（🔴 由你生成）

🔴 **你负责生成完整的背景层**（不是框架提供，不是只写内容）。每个场景的背景必须包含以下元素，且**相邻场景的背景要有差异**（网格角度/粒子密度/ghost 文字/光晕位置都换一换，别所有场景一个样）：

- 深色蓝紫渐变底：#060618 → #0A0C26 → #0C1030（方向可随 mood 微调）
- CSS 3D 透视网格：perspective(800-1200px) + rotateX(55-65deg)，消失点 42% 高度
- ghost text 水印（必须有）：中文关键词 140-200px，透明度 3-6%，z-index 低于内容
- 地平线辉光带（必须有）：蓝紫渐变，位于 top:40-45%
- 粒子雨：≥15 个细长坠线（linear-gradient），两到三层景深，仅上半区，禁止圆形光点
- 扫光：`id="light-scan"`，GSAP x 平移
- 径向光晕：蓝+紫两处

🔴 **背景也要"填满画面"**：背景层铺满整个画布，配合内容层一起把上下左右都填满，禁止四周留出纯黑色空白。

🔴 **z-index 分层铁律（背景 0 < 粒子 2 < 内容 3，违反=代码雨遮挡标题，最常见的画面 bug）**：
- 背景渐变 + 装饰层（网格/ghost 水印/辉光带/粒子雨/扫光/径向光晕）：z-index:0-1
- Three.js 的 `<canvas>`（粒子层）：z-index:2
- 🔴 **内容层 main-content（标题/卡片/数据）：z-index:3 或更高，且 background 必须透明**——必须在 canvas 之上（否则代码雨遮标题），但**绝对不能写 background**。框架根 div 已经铺好深色渐变背景，你在 main-content 上再写 `background:linear-gradient(...)` 会盖住 canvas 的 3D 粒子，导致 3D 动效整个"消失"（最常见的翻车）。main-content 只放内容元素，背景交给根 div。
- 🔴 禁止：`main-content` 写 `z-index:1` 或 `2`（会被粒子压住）、`main-content` 写任何 `background`（盖住 canvas 的 3D 粒子）、`<canvas>` 写 `z-index:0` 或 `1`（被背景盖住粒子白画）、背景渐变写不透明实色盖住粒子

## 🎬 高级技法（每个场景 ≥2 个）

### 1. 逐字渐入（主标题必用）
`<span style="display:inline-block">字</span>` + `tl.from("#main-title span", {opacity:0, y:40, rotationX:-90, stagger:0.04, duration:0.5, ease:"back.out(1.7)"}, 0.2);`

### 2. 毛玻璃卡片
`background:rgba(15,15,46,0.6); backdrop-filter:blur(20px) saturate(180%); border:1px solid rgba(108,140,255,0.15); border-radius:16px;`

### 3. 遮罩揭示
初始 `clip-path:inset(0 100% 0 0)` → `tl.to("#id", {clipPath:"inset(0 0% 0 0)", duration:0.7, ease:"power3.inOut"}, 0.3);`

### 4. 双层发光
`text-shadow: 0 0 20px var(--c1), 0 0 60px rgba(var(--c1-rgb),0.4);`

### 5. blur dissolve
`tl.from("#card", {filter:"blur(12px)", opacity:0, y:30, duration:0.6, ease:"power2.out"}, 0.3);`

### 6. Ken Burns
`tl.from(".scene", {scale:1.06, x:-8, duration:8, ease:"none"}, 0);`

### 7. mix-blend-mode 光晕
`background:radial-gradient(ellipse at 30% 40%, rgba(108,140,255,0.12), transparent 70%); mix-blend-mode:screen;`

## 动效规范

- 🔴 **配音驱动视觉（元素慢慢出来，不是一起弹）**：每个元素有自己的出场时刻，跟口播节奏逐个出现，禁止所有元素同时弹出 = 像 PPT。标准节奏：
  - 0-0.6s：只出主标题（逐字渐入，stagger 0.04s）
  - 0.6-2s：标签 pill 逐个弹出（stagger 0.15s，每个 back.out）
  - 之后：口播说到哪个数据，那个数字才 scale 弹入（scale 2.5→1 + 发光脉动）；说到哪个观点，那个卡片/图表才遮罩揭示/生长
  - 最后一个元素在第 3-4s 才出现，别前 1 秒全铺完
- 入场：tl.from/tl.fromTo，stagger 0.12-0.15s，层次感
- 缓动：内容 power3.out/back.out(1.7) | 呼吸 sine.inOut | 粒子/扫光 none
- 呼吸动画 2-3 个：tl.to repeat:3 yoyo:true
- 🔴 粒子/代码雨下坠要快：0.5s 内位移 ≥ 画面高度的 5%（下坠速度 ≥ 6 单位/s，14 范围）。下坠太慢渲染出来像静态图，用户看不到动态。
- 扫光多样性：除左→右外，可对角线、中心扩散、往返。避免全同一方向

🔴 **动画铁律（违反=画面呆板）**：
1. **最少 8 个入场动画**：每场景 ≥8 个 `tl.from()`/`tl.fromTo()`，少于 8 个不合格。入场顺序：背景装饰层→ghost→主标题(y:-50→0)→数据卡片(y:60→0, back.out(1.7))→辅助元素→底部信息，交错 0.12-0.15s。
2. **三属性入场**：每个元素入场同时改变 ≥3 个 CSS 属性（y+scale+opacity），禁止只有 opacity 的单属性淡入。
3. **五层视觉栈**：背景渐变(z:0)→氛围粒子(z:1)→图形/卡片(z:2)→色彩光晕(z:3)→扫描线/高光(z:4)。禁止少于 3 层。
4. **快出慢入**：出场比入场快。入场 0.6-1.0s，出场 0.2-0.4s。
5. **静态元素呼吸**：所有静态元素加 scale 1.0→1.015→1.0 呼吸（duration 3-4s, repeat:3, yoyo:true, sine.inOut）。
6. **禁线性缓动**：入场 back.out(1.7)/power3.out，呼吸 sine.inOut。禁止 linear/none/power1。

🔴 **数据具象化（每场景至少 3 种）**：数字冲击(scale:2.5→1+发光脉动) / 进度条(width:0%→目标+百分比) / 趋势箭头(↑↓+百分比) / 迷你图表(5-7 bar 或 SVG 折线) / 对比条(A vs B+差值)。

🔴 **数据"慢慢出来"，但数字必须写真实值（静态），禁止 countUp**：
- 大数字：直接写真实数字（如"2000万""-87%""8亿"），用 scale 弹入（scale 2.5→1）+ 发光脉动。🔴 禁止 countUp 从 0 数——渲染引擎是 seek 驱动（跳转到时间点截图），countUp 依赖 onUpdate 回调，seek 时不触发，数字会永远停在 0，画面全变 0。数字必须一步到位写真实值
- 进度条：width 从 0% 生长到目标（duration 1s power2.inOut）—— 安全（width 是 CSS 属性动画，seek 正确插值）
- 趋势线/折线：SVG stroke-dasharray 从 0 绘制（像画画，duration 1-1.5s）—— 安全
- 柱状图：每根柱子 scaleY 0→1 生长（stagger 0.12s）—— 安全

🔴 **色彩饱和度铁律（禁灰蒙蒙）**：主色饱和度 ≥60%。核心数据必须高亮色(金#FFD700/青#00D4FF/紫#A855F7)，禁止灰色。卡片边框带颜色 rgba(主色,0.3)，禁止白/灰边框。
