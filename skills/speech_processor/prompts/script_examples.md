# 口播文案质量标尺（精华范例，学"特征"不是抄"结构"）

下面是 5 个维度的好坏范例。写文案时对照这些标尺，不要照抄这些句子的结构，学的是它们背后的"力度"。

## 1. 钩子：颠覆认知 + 情绪冲击（不是温和代入）
✅ 能把一群听话的牛马养到近乎绝种，不是劳动者的懈怠，而是饲养者的彻底失败。
✅ 掩盖一场雪崩的最高级方式，不是修补堤坝，而是扔给公众一块带血的桃色八卦。
✅ 国内XX带来的恶果，已经进入了全新阶段。（"新阶段"式断言，制造"你out了"的紧迫感）
❌（差，戳不痛）你身边有没有这样的人？三十多岁了，一提到结婚就沉默。

## 2. 数据：跨制度对比，钉死一个判断（不是罗列给画面凑数）
✅ 日本去年出生67.1万，比40年前少一半；韩国总和生育率0.72全球倒数第一；意大利35.5万二战后最低——全球195国里绝大多数低于更替线。这不是某国的偶发，是系统性的全球塌方。
❌（差，单点撑不起判断）初婚年龄推后4岁，房价收入比30。

## 3. 框架：给它起个名字（进阶：学科术语 + 大白话翻译）
✅ 两股力量：工业化=时间贫困，抽干人的精力；信息平权=算明白了账。一上一下夹着生育率。
✅ 这在心理学上叫「防御性关系退缩」。大白话就是：当人感知到可能身败名裂的风险时，大脑会自动切断所有试探的触角。
✅ 这在社会学里其实就是一种「信任链条垄断」。
❌（差，没名字的泛词）这是结构性问题。

## 4. 金句：每段都有、可截图、对仗有节奏（可引用名人名言）
✅ 孩子生下来是继承我的劳碌和贫困，不生才是善良。
✅ 谁先走心谁就输。
✅ 酒杯太浅，敬不到来日方长；巷子太短，走不到白发苍苍。
✅ 培根说过：怀疑往往会像蝙蝠一样在黑暗中飞翔。

## 5. 结尾：反转 / 闭环 / 升华（加分）
✅ 他以为自己很快就能掌控这个游戏。其实他什么都不懂，就像当年的你一样。
✅ 死死守住你对一个具体的人的感知能力。
