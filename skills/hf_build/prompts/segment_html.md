## 🎨 配色铁律（🔴 必须遵守，违反整卡作废）

**单一蓝色科技风，整卡只用一个主色系**：深色蓝紫渐变底 + 霓虹青蓝 `#00d4ff` 做强调。

- 主色：蓝 `#6c8cff` / 青 `#00d4ff`，深底 `rgba(15,18,40,0.65)`
- 强调：只用 **1 个** 点缀色（青或紫），最多 1-2 处（比如 1 个数字、1 个图标）
- 🔴 **禁止多色混搭**：不要黄数字 + 青进度 + 紫标签 + 蓝标题这种"每个元素一个颜色"的花里胡哨。整卡要看起来是"同一个色系"，只有 1-2 个点被点亮。
- 🔴 **禁止红/橙/绿**。
- 文字以白 `#ffffff` / 浅灰为主，只有关键词用青蓝点亮。

## 🔴 硬性要求

1. 生成**一个** HTML 容器（`<div>`），里面包含**所有**卡片
2. 每张卡片必须用 `<div class="seg-card" data-seg="{i}">` 包裹（i 从 0 开始按顺序递增）
3. 卡片按口播顺序**竖排**（`display:flex;flex-direction:column;gap:14px`），从上到下堆叠
4. 🔴 **卡片 = 关键词高亮（2-6 字），不是整句照抄**：
   - 卡片写的是从原文里提取的**核心词**（2-6 字），放大点亮。**绝对禁止照抄整句**（整句在底部字幕里，照抄会重复显示）。
   - ✅ 正确：原文"我终于把自己的大脑给剥离出来了" → 卡片只写"大脑剥离"
   - ❌ 错误1：卡片照抄"我终于把自己的大脑给剥离出来了"整句（和底部字幕重复，失败）
   - ❌ 错误2：卡片写"蜕变时刻 / 混乱→清晰的蜕变"（编造，原文没有，失败）
   - 🔴 每个卡片只写 1 个关键词（2-6 字），关键词必须能在原文里找到。其余内容靠底部字幕表达，不要写长句。
5. 🔴 **绝对不要写 `<script>` 标签，不要写任何 GSAP 动画代码**——代码层会注入"依次弹入"的时间线，你只负责静态布局
6. 🔴 **半透明背景（透出背景视频里的人物，绝不能用不透明黑块遮挡人脸）**：
   - 外层容器（包住所有 seg-card 的那个 div）**绝对禁止写 `background`**（保持透明，只做 flex 布局和留白）
   - 每张 seg-card 的背景用 `rgba(...)`，**alpha ≤ 0.7**（如 `rgba(15,18,40,0.65)`），透出人物；禁止纯色 `#` 背景（不透明黑块遮挡人物 = 失败）

## 输出

只输出 HTML（div 结构，无 `<script>`、无解释文字）。
